# 보수적 PDF 변환 전략

## 모드와 현재 조립 결과

| 모드 | 자동 판정 조건 | 빈 문서 조립 결과 |
| --- | --- | --- |
| `editable` | 긴 본문, 낮은 이미지 비중, 단순한 벡터 구성 | 추출 텍스트를 편집 가능한 흐름 문서로 배치 |
| `hybrid` | 설명문과 그래픽이 섞였고 독립 미디어 영역이 확인됨 | 중복을 막기 위해 현재는 전체 쪽 래스터 한 장으로 배치 |
| `raster` | PPT 슬라이드, 복잡한 도면·표·차트, 합성 시뮬레이션, 스캔 | 전체 쪽을 원본 비율 유지 이미지로 배치 |

자동 판정은 보수적 초안이다. `hybrid` 후보에서 의미 있는 미디어 크롭을 만들 수 없으면 분석기가 `raster`로 낮춘다. 래스터 쪽에는 사용하지 않을 개별 미디어 크롭을 만들지 않는다.

## 대상 HWP 양식이 있을 때

PDF의 페이지를 빈 문서에 통째로 복제하지 않는다. 대상 양식의 머리말, 꼬리말, 장 번호, 여백, 글꼴과 필드 구조를 유지하고 `apply`로 값과 이미지를 채운다.

이미지 필드는 다음 순서로 준비한다.

1. 지도·사진의 주석, 라벨, 범례를 한 이미지에 포함한다.
2. 대상 셀의 비율을 확인한다.
3. 표 셀은 `cell-fill`, 셀 밖은 명시적 크기의 `inline`으로 삽입한다.
4. 출력 PDF와 렌더 PNG에서 왜곡·잘림을 확인한다.

## 양식이 없을 때

`assemble --confirm-no-template`는 내용과 기하 보존을 우선하는 초안이다. manifest의 각 선택 쪽은 별도 HWP 구역이 되며, 원본 pt 크기와 방향을 mm로 변환하고 5 mm 여백 안에 단일 비율로 맞춘다. A4 세로와 A3 가로 같은 혼합 기하도 쪽별로 유지한다.

현재 반복 배치 규칙은 다음과 같다.

- `editable`과 유효한 `text_file`: 텍스트만 배치한다.
- `editable`인데 텍스트 자산이 없거나 `hybrid`/`raster`: 전체 쪽 래스터만 배치한다.
- 텍스트와 전체 쪽 래스터, 또는 전체 쪽 래스터와 개별 미디어를 동시에 넣지 않는다.

## 알려진 한계

- PDF 폰트가 글자 매핑을 제공하지 않으면 텍스트 추출이 깨질 수 있다.
- PPT 그룹 도형, SmartArt, 복잡한 차트는 HWP 개별 객체로 자동 복원하지 않는다.
- `hybrid`의 텍스트+그래픽 좌표 재구성은 이번 버전 범위가 아니다. 확실하지 않으면 전체 래스터를 사용한다.
- 운영 검증은 빈 쪽·쪽 수·기하·가장자리·해시·시간을 확인하지만 의미와 시각적 동일성은 사람이 비교해야 한다.
- 상업 배포 전에는 한컴 Automation 사용 조건을 별도로 확인한다.
